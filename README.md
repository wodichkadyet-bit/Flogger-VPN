⚙️ Возможности проекта

- 🔄 Автоматическое обновление подписки.
- 🔍 Проверка доступности серверов.
- 🧹 Удаление нерабочих и устаревших записей.

- 🌍 Разные страны и локации.
- 📡 Сбор конфигураций из открытых источников.

📅 Обновление

Подписка обновляется автоматически через GitHub Actions.

Интервал обновления: каждые 2 часа.

Срок хранения конфигураций: до 7 дней.

---

📱 Как подключиться?

1. Скопируйте ссылку на подписку.
2. Откройте приложение Happ.
3. Нажмите "+".
4. Выберите добавление подписки из буфера обмена или по URL.
5. Вставьте ссылку и обновите список серверов.

⚠️ Важная информация

- Проект предоставляется бесплатно.
- Доступность серверов не гарантируется.

- Не используйте неизвестные серверы для передачи конфиденциальных данных.
